built using BlackBerry JDE 4.5.0 and JDK 1.5.0_22

functional:
-list of last 25 chats
-seeing messages (and from whom)
-sending messages (including some special characters)
-replying to messages
-saving settings
-loading screens
-displaying exceptions without softlocking the user

internal functionality:
-getting item from json
-generating a list of strings from a text with format ["string 0", "string 1", ...]
-sending and recieving messages from a socket connection (the ip adress can me changed in settings)
